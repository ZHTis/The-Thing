# 绘图技巧跟踪

每次完成绘图后，检查本次是否有值得复用的新方法或纠错；有则更新用户技能库，没有则不重复写。

- 按输出格式分开记录，例如 STEP、SVG、PNG、PDF、DXF、HTML、MP4；同格式的不同方法可在同一技能内分段。
- 先查已有个人技能，合并去重；不改系统或插件自带技能。新技能放在用户技能目录，名称使用 drawing-格式-用途。
- 每份说明尽量简短：用途 → 实际工具 → 最少步骤/核心命令 → 检查方法 → 已验证的注意点。只记录实际用过、有证据的方法；估算、失败尝试与成功方法明确区分。
- 图纸尺寸、具体产品参数留在项目文件；技能仅保存通用方法，可附一个真实案例的代码路径。临时运行环境路径不能作为长期依赖。
- 保留已有内容，只增加有用的新知识或修正错误；不为收集技巧而扩大绘图任务，也不保存对话全文、凭据或无关个人资料。
- 修改后验证技能格式、引用与适用范围。对用户最多简短说明本次新增了哪些技巧；无更新无需汇报。
- 仅根据当前可访问的工作记录积累；不要声称已回顾全部历史对话。此规则随对话执行，不设后台监控。
