# 统一数据与模型适配

本技能规定接口和校验流程，不代表已有可运行的数据处理程序。优先复用项目现有工具；涉及样本来源、划分和组批时读取并遵循[neural-data-splits-batches](../neural-data-splits-batches/SKILL.md)，由该技能管理划分清单。

## 先核实来源，再生成建议

解释或建议四个数据集（Du-IN、VocalMind、SingleWordProductionDutch、NaturalSpeech/ds004703）的处理时，先执行以下流程；数据与模型接口设计也沿用此流程。

1. **定位版本**：明确数据集、任务/模式、发布版本，以及原始波形、已切段数据或派生特征。记录待回答的具体问题，避免用另一版本或另一任务的事实代替。
2. **查作者依据**：先读原论文相关方法、数据说明和补充材料，再追踪其中的官方数据仓库、工具代码及元数据文件。聚焦当前问题；已有可追溯且版本匹配的证据可复用。完成标准是能指出相关章节/文件，或明确指出尚未访问的材料。
3. **核对工具和实物**：查实际读取器、处理配置和本地代表性文件；核实维度、单位、参考、采样率、时间锚点、标签、坏道/QC、归一化拟合范围或划分中与问题有关的项。模型迁移另核对checkpoint逐键兼容性。论文与代码不同，分别报告；保持本地修改与作者原版的区分。
4. **列清证据状态**：区分“作者声明已完成”“官方代码实现”“本地实际验证”“未知/推断”“本项目新增建议”。作者做过的审核记为继承的来源证据，不能写成本地人工复核。未报告或未检索到的事项记为未确认，不据此断言作者没做。
5. **只针对缺口提建议**：每项建议说明依据、解决的具体问题、是否影响当前目标，以及是否改变作者协议。优先复用作者处理；只有版本差异、解析异常、实际疑点或新评估目标需要时才建议复核，给出触发原因。完整trial分类、声学回归和精细时序分析的要求分别判断，不把所有可选QC变成统一准入障碍。
6. **核查后回答**：先给对当前任务有用的结论，再给直接来源链接/代码位置和实际限制。证据不足则给条件性结论及下一项可完成的核验；不能用建议补成事实，也不能用形状通过代替数据语义或效果验证。

VocalMind的常见分支：作者的音频读错排除、临床坏电极排除、同步声明与本地额外削顶候选检查分别记录；原始CSV与处理后特征的参考/归一化历史分别核对。Du-IN的常见分支：发布波形单位与z-score后无量纲输入分别解释，核对官方代码的统计轴及划分前后顺序。每次以访问到的版本为准，不把这些例子当作无需核查的固定数据事实。

## 统一数据包

保留不可改写的原始文件或可验证的原始文件引用，避免强制复制大文件。数据包包含版本、原始文件路径及校验标识、波形引用、事件/标签表、通道表、采样率、信号单位、时间原点及所属时钟、样本来源、QC记录、划分清单引用。沿用已有BIDS/NWB等有效组织，不为统一接口破坏其结构。

记录真实参考方式、通道类型、顺序、坏道、坐标单位和坐标系；如模型需要，补充电极杆、接触点编号与atlas脑区。缺失值显式标记，空间坐标变换需有来源，不能以零坐标假装位置有效。离线数据已预处理时记录已知历史与未知环节，避免重复滤波或标准化。

## 可配置预处理

把QC、滤波/陷波、参考、重采样、事件切段/滑窗、标准化、频谱/频带特征、通道选择/融合/PCA拆为有序模块。每个模块声明输入输出语义、参数、是否需要fit、拟合数据范围及时间/通道映射。模块顺序可配置但应校验依赖，例如滤波频率与Nyquist、重采样抗混叠和事件索引更新。

原始数据包保持完整；模型分支生成派生数据，禁止为方便所有模型而永久统一降采样或通道降维。拟合型处理和跨集合边界规则遵循划分技能。记录窗口内固定归一化与全session统计归一化的区别，披露测试数据统计的使用。

## 三类适配器

根据真实接口选择分支，不按模型名字硬编码假设：

- 波形：默认规范输出[B,C,T]，声明单位、sfreq及通道顺序；模型需要[B,T,C]时仅在边界转置。
- 专属前处理/解剖信息波形：在波形之外传入模型需要的坐标、脑区、接触点名称、subject_index或mask。明确STFT、重采样、归一化是在外部还是forward内部完成，确保只执行一次。
- 逐电极特征：输出[B,C,F]，F是特征维而非时间。记录上游编码器、checkpoint、特征层、池化和窗口定义，保留逐电极轴；送入空间聚合模型前不提前平均通道。

变长数据仅在模型确实支持时填充并传有效mask；否则用兼容配置分组batch。通道选择/插值/融合需保存输入输出映射和缺失处理。可学习融合由训练过程拟合，不在全数据离线预拟合。

## 模型与权重契约

逐模型建立版本化输入契约：库版本/提交、轴语义、dtype、单位、采样率、窗口长度、patch限制、通道数量/顺序、参考与归一化、元数据与mask要求、输出形状、标签词表/编码和loss约定。按实际安装代码及对应权重配置核验，不能把开发版网页当作已安装接口。

区分随机初始化和预训练适配。权重记录仓库、revision、文件hash、许可、训练数据/被试和已知接触范围、架构配置、是否包含已训练任务头。仅有from_pretrained方法不算确认权重可用；区分文档宣称、已下载、已加载、已验证。逐被试固定通道权重不因形状相同就与新被试兼容。适配或重建分类头后明确哪些参数加载、丢弃、冻结和重新训练。

## 缓存、对照和完成标准

派生缓存以数据版本、样本ID、预处理配置、fit所属fold与拟合参数hash、模型/权重版本及特征层标识，避免跨fold复用已拟合特征。训练期随机增强保留随机策略，不误缓存成所有epoch同一增强。

对比复用来源和划分；分别标明统一前处理的结构对比与各自权重配方的完整方案对比。输入消融记录改变的模块及随之改变的输入信息。

实际接入后检查真实batch的sample_id对应、轴含义、有限值、单位/采样率、通道映射、mask、标签范围及模型输出；预训练加载报告missing/unexpected keys，对不兼容项显式报错或报告经过确认的适配。交付配置、契约、变换记录及检查结果，分别标记设计完成、运行通过和效果验证；形状通过不等于语义兼容或模型有效。
