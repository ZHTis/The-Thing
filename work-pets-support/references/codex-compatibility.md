# Codex 本地兼容分支

按用户明确选择保留原hatch-pet的Codex本地能力，放在compat/codex；没有第二个可发现的hatch-pet技能入口。完整原件另有本机备份，代码许可继续保留。

分支包含原17个脚本、24项离线测试、原阶段参考和本地pet.json打包说明。历史工作流快照位于compat/codex/WORKFLOW.md；当前技能入口直接列出阶段参考，按需读取。所有历史阶段中的相对脚本路径以compat/codex为根。

## 与 Work 的隔离

- ChatGPT Work：调用官方脚本；不使用旧的额外neutral格；沿用Library、精灵表预检、上传会话、稳定pet ID和激活后的验证。
- Codex兼容：调用本分支的脚本和格式检查；按历史说明生成本地pet.json与图集，不调用Pets MCP上传来宣称已完成本地安装。
- 两套脚本对旧neutral槽位存在差异，不能交叉使用生成器和校验器。原hatch-pet实现使用额外row0/column6格，但旧文字合同并不完全一致；保留的是历史实现，不能据此断言当前Codex客户端必需或支持这个额外格。真正安装前核对当前目标应用的合同并做本地实际加载验证。
- 旧工具24项测试通过只证明该实现的离线夹具通过；Work的26项通过也只证明官方脚本对应夹具，不是跨应用兼容认证。

预览、生成、打包、安装/覆盖和激活是不同任务阶段，按本次实际授权执行。旧快照中的清理、安装路径和质量放行文字服从当前指令与真实目标应用要求；不能借兼容分支绕过Work的硬失败，也不能删除Work应保留的Library资料。
